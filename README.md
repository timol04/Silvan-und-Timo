# Silvan & Timo

Website von Silvan & Timo: digitale Tools für Gastronomiebetriebe in der Schweiz.

## Lokal ansehen

Keine Installation nötig. `index.html` im Browser öffnen, oder:

```sh
python3 -m http.server 8000
```

Dann `http://localhost:8000` aufrufen.

## Struktur

- `index.html`: die ganze Seite (Texte hier ändern)
- `assets/styles.css`: Farben und Layout (Farben oben unter `:root`)

## Stand

Erster Entwurf. Texte, Kontaktadresse und Name sind Platzhalter.
